# Security baseline

- Enforce role-based access control and geographic scope on the server.
- Configure and test PostgreSQL Row Level Security before exposing user data.
- Never put Supabase service-role keys in client-side code or public repositories.
- Keep candidate CVs and verification documents in private storage buckets with short-lived signed access.
- Validate file types, sizes and ownership.
- Rate-limit authentication, enquiries and reporting endpoints.
- Maintain audit logs for privileged actions.
- Use separate development, staging and production environments.
- Establish backup, restore and incident-response procedures before launch.
- Obtain legal review for privacy, retention and Nigeria Data Protection Act obligations.
